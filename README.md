# Reaction-front diffusivity

MATLAB code and input data accompanying:

Khakimova, L., Schmalholz, S. M., and Podladchikov, Y. Y. (2026). **Beyond hydraulic diffusion: reaction front propagation and timescales in metamorphic (de)volatilization processes.** *EGUsphere* [preprint]. [doi:10.5194/egusphere-2026-3107](https://doi.org/10.5194/egusphere-2026-3107).

## Scientific scope

The repository contains analytical and numerical calculations of fluid pressure-driven reaction fronts in porous rocks. The model combines one-dimensional mass conservation, Darcy flow and a pressure-dependent total density. The analytical solutions describe a single reaction front and two coupled fronts in the quasi-stationary regime.

The scripts compare analytical and numerical front propagation, distinguish effective front diffusivity from hydraulic diffusivity, and estimate permeability and reaction timescales for experimental and natural metamorphic reactions.

## Repository contents

| File or folder | Description |
| --- | --- |
| `run_all.m` | Entry point for Figures 2-8 and A1. Runs the eight figure scripts in manuscript order and records MATLAB version information and command-window output. |
| `matlab/FIG_2.m` | Single-front dehydration and hydration: constitutive relations, pressure and density profiles, and numerical and analytical front histories. Compares saved results of this study with those of Schmalholz et al. (2024). |
| `matlab/FIG_3.m` | Time-dependent simulations of two coupled reaction fronts for devolatilization and volatilization, with analytical comparisons and an animation. |
| `matlab/FIG_4.m` | Trailing-to-leading front velocity ratio as a function of effective-diffusivity and density-jump ratios, using the solution in Appendix A. |
| `matlab/FIG_5.m` | Effective-to-hydraulic diffusivity ratio for four pressure differences and a fixed poroelastic modulus, with density ratios for seven metamorphic reactions. |
| `matlab/FIG_6.m` | Numerical pressure profiles for constitutive relations with zero, one and two reactions, illustrating reaction-induced retardation. |
| `matlab/FIG_7.m` | Permeability estimates from field front distances and durations, and propagation times for seven reaction-induced density changes. Field examples follow Beinlich et al. (2020), John et al. (2012) and Taetz et al. (2018). |
| `matlab/FIG_8.m` | Hydraulic, single-front and coupled-front permeability estimates for gypsum dehydration, together with digitized porosity profiles from Fusseis et al. (2012). |
| `matlab/FIG_A1.m` | Schematic pressure profile and piecewise-linear constitutive relation for the two-front solution in Appendix A. |
| `data/` | Four saved single-front simulation datasets and digitized experimental profiles. Variables, dimensions and sources are described in [data/README.md](data/README.md). |
| `reference/FIG_2.png` | Reference rendering of Figure 2 for visual comparison. |
| `figures/` | Output directory for generated PNG files, the animation and the MATLAB session log; created during execution. |
| `CITATION.cff` | Machine-readable repository citation metadata. |

Figure 2 is plotted from the saved simulation datasets. The solvers that generated those datasets are not included. Figure 1 has no generation script in this repository.

## Execution and dependencies

The full figure sequence is generated by running `run_all` from the repository root in MATLAB:

```matlab
run_all
```

Individual figures are generated by the corresponding scripts in `matlab/`. Data and output paths are resolved relative to the scripts. Results are written to `figures/`; Figure 3 also writes `DEVOL_2Fronts.gif`, and the complete run records `run_log.txt`.

MATLAB with graphics support is required. The scripts use array operations, interpolation, plotting and image output, including `xline`, `yline` and `getframe`. Figure 3 records its animation from an open figure window. ThermoLab and Perple_X are not runtime dependencies.
